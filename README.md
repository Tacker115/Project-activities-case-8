# Seoul Bike Demand Prediction

**УрФУ — Проектный практикум, кейс №8**

Прогнозирование почасового спроса на городской велопрокат в Сеуле с использованием машинного обучения.

## Данные

- **Датасет:** 8 760 наблюдений, 14 признаков/столбцов
- **Задача:** регрессия
- **Целевая переменная:** `Rented Bike Count`
- **Исходный файл:** `data/raw/SeoulBikeData.csv`
- **Очищенные данные:** `data/processed/SeoulBikeData_clean.csv`

**Источник:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand) (CC BY 4.0).

Проект в разработке.
